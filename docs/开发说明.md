# 开发与源码边界

`deployment/aliyun-harness` 保存自行维护的集成代码，`scripts` 负责在新机器安装官方发行物、生成本机配置与检查运行状态。不将生产配置、上游 node_modules、代理核心和网页发行包提交到 Git。

## 修改后检查

```bash
bash -n scripts/install.sh scripts/publish.sh
python3 -m compileall -q scripts deployment/aliyun-harness tests
python3 -m unittest discover -s tests -v
node --check deployment/aliyun-harness/web-enrollment/index.mjs
node --check deployment/aliyun-harness/web-enrollment/client.js
```

安装脚本会改变系统软件和服务，只应在全新隔离测试机执行，不能对生产机运行测试。生产环境的历史具体说明留在本地 `docs/当前生产部署记录.md`，由gitignore排除。

## 提交与凭据

当前目录包含一些早期机器专用脚本，它们没有纳入 Git；不要使用 `git add -f` 把这些运行记录加入仓库。检查 `git diff --cached`，确认没有密钥或订阅。CI只是基础检查，不代表网络、所有上游版本、Windows或安卓全流程已验证。
