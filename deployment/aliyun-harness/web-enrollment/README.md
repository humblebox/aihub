# 手机访问与网页添加设备

统一入口为 `https://你的服务器/login`，手机与电脑均使用管理员账号密码，不需要复制启动令牌。当前为同一管理员工作环境，不提供多用户隔离。

## 接入流程

1. 登录后打开设置 → 添加远程设备，或 `/devices`。
2. 选择 Linux、Windows 或安卓，填写唯一标识与名称，生成设备专属命令。
3. 在目标电脑项目目录执行命令，自动使用该目录作为初始工作区。
4. 回到网页刷新远程设备，选择设备、目录并新建会话。

Linux 支持 Ubuntu/Debian x86_64，首次安装需要 sudo。Windows使用管理员PowerShell和Git Bash；安卓使用Termux。Windows/安卓尚待完整实机验证。接入命令默认一小时有效，不应公开。

## 结构

Nginx 通过统一登录检查保护公网HTTPS，Harness仍保留原生认证。网页插件向本机受限 Unix socket 请求设备接入命令；root管理进程只执行固定操作，不给网页进程通用sudo权限。SSH22用于短期安装包下载和注册，FRP7000用于设备主动连接，映射SSH端口仅在云服务器回环地址开放。

源码同时提供 `/clash` 管理页及设置中的修改密码入口。完整代理界面使用独立的Zashboard上游构建。
