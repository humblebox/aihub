# 统一网页登录

固定地址为 `https://你的服务器/login`，用户名为 admin。初始随机密码保存在服务器 `/root/aihub-initial-login.txt`，服务副本位于 `/var/lib/aihub-login/初始登录信息.txt`，权限均为 0600。不要提交密码文件。

服务 `aihub-login` 仅监听 127.0.0.1:3081，由 Nginx HTTPS 提供登录页面。账号文件 `/var/lib/aihub-login/account.json` 保存 scrypt 密码哈希、盐及独立会话签名密钥，不存明文密码。统一登录会话有效期为30天，使用 Secure、HttpOnly、SameSite=Strict Cookie；同一IP十分钟内最多十次失败尝试。

登录成功后，服务读取当前 Harness 启动地址，在本机通过其原生令牌接口交换浏览器会话；不会关闭 Harness 认证，也不会将启动令牌放到公开地址。Nginx 使用 auth_request 保护 AI、设备及代理管理入口。旧启动链接不再能绕过统一登录。

服务重启后会话签名密钥不变。Harness 原生会话如果失效，重新访问 /login 登录即可。当前 HTTPS 仍是自签名证书，统一登录不解决证书信任问题。

退出接口为同源 POST /logout。账号当前为单管理员，共享同一 AI 工作环境，不提供多用户隔离。请求密码及 Cookie 不写应用日志。安装器仅用于全新环境，既有部署升级前应自行备份 Nginx 配置。

已验证匿名页面跳转、错误密码拒绝、正确密码交换两层会话、登录后 AI/设备/Clash/Zashboard 访问及退出登录。网页登录操作未做浏览器视觉验证。

修改密码入口：`/account/password`，需要已登录、旧密码及两次相同新密码（至少1个字符，不设单独位数上限）。修改时轮换统一会话签名密钥，所有设备重新登录；新密码不保存明文。设置中的「登录账号」也提供入口。原始密码文件在服务器上会标记失效，本地初始密码文件不会自动更新。

表单使用签名双提交防伪令牌；兼容自签名证书环境中浏览器发送的 Origin:null，仍拒绝其他站点来源。已验证 Origin:null 登录、错误旧密码、防伪令牌；在隔离实例验证修改成功、哈希存储和旧会话失效，未修改实际账号密码。
