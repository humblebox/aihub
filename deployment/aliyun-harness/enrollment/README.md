# Linux 终端一键接入

适用范围：Ubuntu／Debian、x86_64、systemd。其他 Linux 发行版已安装并启用 `ssh` 服务后可尝试，但尚未实测；Windows 与安卓使用网页中的对应系统选项，详见 [跨平台接入](跨平台接入.md)；Linux ARM 暂不支持。
远程工作继续使用现成的 dsh-remote 插件；此目录仅补充 SSH／FRP 接入过程。
目标电脑无需安装 Harness、Node.js 或 AI 模型，也无需手动复制安装文件或填写项目路径。

## 通过网页选择系统

在“设置 → 添加远程设备”选择 Linux、Windows 或安卓，再生成命令。Windows 在管理员 PowerShell 执行，安卓在 Termux 执行。详情和限制见 [跨平台接入](跨平台接入.md)。

## 服务器终端生成命令

推荐在网页 `/devices` 生成。也可在服务器执行：

```bash
sudo python3 /opt/aihub/enrollment/enroll_server.py create linux03 --name "第三台Linux" --platform linux
sudo python3 /opt/aihub/enrollment/enroll_server.py command linux03
```

每台设备单独生成，不要公开限时接入命令。默认60分钟有效，可在create时使用 `--minutes 120` 调整。

## 目标电脑：在项目目录直接粘贴

打开目标电脑终端，进入希望 AI 操作的项目目录，粘贴生成器输出的完整接入命令即可。
如果终端已经位于项目目录，直接粘贴执行，无需额外切换目录。
安装程序自动获取执行时的 `os.getcwd()`，不需要填写 `--workspace`，也不需要手动复制文件。

目标端会自动通过现有云端 SSH 22 端口下载私有安装包、解包到临时目录、执行安装并清理临时文件。
下载和注册都使用专属受限凭据，不能执行云端任意命令；云端 SSH 主机公钥已固定在命令中。
不额外开放下载端口，不需要配置域名或 HTTPS 下载服务。

首次安装需要输入 sudo 密码，以安装或启用 SSH、创建并启动 FRP 系统服务。
请以日常使用的普通账户运行，不要额外加 `sudo`，否则会把 root 当作目标账户。
目标电脑需要 Python 3；Ubuntu 通常自带。缺少 SSH 客户端时会尝试用 sudo 和 apt-get 安装。

## 自动完成的步骤

1. 自动下载此设备专属安装包，检查系统及接入有效期。
2. 安装并启用 OpenSSH，将该设备独立的云端 SSH 公钥加入当前账户。
3. 写入私有 FRP 配置，安装以当前账户运行的系统服务，退出桌面登录后仍可保持连接。
4. 使用限时注册凭据回传用户名、当前目录及 SSH 主机公钥。
5. 云端严格校验隧道中的主机公钥、SSH 登录和项目目录。
6. 写入 SSH 别名，通过 dsh-remote 原有认证接口登记设备，不切换其他会话的目标。
7. 注销首次注册凭据，删除云端安装包及接入命令文件；目标端自动清理临时解包目录和下载文件。

首次注册成功后凭据失效；FRP 使用现有服务的长期共享令牌，注册过期不等于撤销已安装的隧道。

## 网页选择

Harness 网页 → 设置 → 远程工作区，刷新列表。
新设备已经保存名称、SSH 后端和项目目录。选择对应主机，打开目录并新建远程会话。
原有会话不会自动切换目标。

## 查看或取消尚未使用的接入凭据

在阿里云服务器执行：

```bash
python3 /opt/aihub/enrollment/enroll_server.py list
python3 /opt/aihub/enrollment/enroll_server.py cancel linux03
```

取消会阻止首次下载和注册，删除云端安装包与接入命令。
它不会撤销共享 FRP 令牌，也不是移除已接入设备的命令。

## 排查

目标电脑查看系统服务：

```bash
sudo systemctl status aihub-frpc-linux03
sudo journalctl -u aihub-frpc-linux03 -n 30 --no-pager
```

目标电脑需要能访问云端 TCP 22（下载及限时注册）和 TCP 7000（FRP 隧道）。
默认转发目标电脑本机 SSH 22 端口，不需要处于同一局域网。
首次注册失败时，确认目录、SSH 服务和网络，在有效期内重新执行原命令；成功后无需重复执行。

## 验证范围

已实测 SSH 自动下载、当前目录参数传递、任意云端命令拒绝、独立隧道、严格 SSH 校验、云端别名及插件列表自动登记、注册凭据重放拒绝，并清理测试设备。
目标电脑上的 sudo 安装及 systemd 系统服务创建尚未在当前账户下完成实测，因为需要交互输入 sudo 密码。
Python 源码通过语法检查。云端已有设备和网页服务保持正常。

普通账户 SSH 权限并不局限于项目目录；选定目录不是操作系统隔离。

## 一行接入命令

在网页 `/devices` 选择系统并生成接入命令，再到目标机器的项目目录粘贴执行。新命令通过 HTTPS 限时链接下载启动脚本，保留当前工作目录，无需手动复制文件。Linux／安卓需要 `curl` 和 Bash；Windows 使用管理员 PowerShell 和系统自带 `curl.exe`。

自签名证书使用 `--pinnedpubkey` 固定服务器公钥。不要删除该参数；证书公钥更换后应重新生成命令。命令含私有随机接入凭据，默认一小时有效；设备接入成功或取消后下载入口立即失效。下载入口不写入 Nginx 访问日志，不需要目标机器登录网页，也不提供其他文件访问权限。原有长命令继续兼容，新生成的命令自动使用短格式。
