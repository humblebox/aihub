# Windows 和安卓接入

在任意浏览器登录 AIHub，进入“设置 → 添加远程设备”，选择系统、填写唯一设备标识和名称，生成接入命令。
每台设备生成独立命令，一小时内使用。执行时自动使用当前终端目录，不需要复制安装文件。

## Windows 10／11 x64

1. 使用本机 Windows 管理员账户，打开“管理员 PowerShell”。
2. 进入希望 AI 操作的项目目录，例如 `cd D:\Projects\demo`。
3. 粘贴网页生成的整条命令并执行。
4. 回到网页远程工作区，刷新列表，选择设备和目录，新建会话。

安装器启用系统 OpenSSH 服务，加入设备独立公钥，部署官方 FRP 0.71.1，并创建开机运行的计划任务。
为兼容现成远程插件的 POSIX 命令，安装器通过 winget 安装 Git for Windows；已有默认路径的 Git Bash 时直接复用。
缺少 winget 时请先安装 Git for Windows，再重新执行。SSH 可选功能安装可能需要 Windows Update 网络访问。
不自动改写 SSH 默认 Shell。管理员账户公钥使用 Windows 默认的 `administrators_authorized_keys`；自定义路径配置会拒绝安装，防止猜测错误。
目前面向本机账户、本机磁盘路径；不支持域账户、UNC 路径、Windows ARM64。
AI 通过该 Windows 管理员账户执行远程任务，权限较高；不提供桌面点击或图形应用控制。

计划任务名称：`AIHub-frpc-设备标识`。
配置路径：`C:\ProgramData\AIHub\设备标识`。
如果首次注册失败，可在有效期内重新执行；不支持自动卸载或回滚系统 OpenSSH 安装。

## 安卓 Termux

先从 Termux 官方推荐渠道安装 Termux，例如 F-Droid 或官方 GitHub。不要把命令粘贴到浏览器地址栏。

1. 打开 Termux，进入项目目录；没有项目时可以 `mkdir -p ~/projects/demo && cd ~/projects/demo`。
2. 粘贴网页生成的安卓命令，允许软件包安装。
3. 成功后在网页远程工作区刷新列表、选择设备和目录。

命令从 Termux 仓库安装 Python、OpenSSH、frp 和 termux-services，不使用不兼容的普通 Linux 可执行文件。
SSH 使用 Termux 默认 8022 端口，FRP 向云端建立连接，不需要 root。
后台进程由 termux-services／runit 管理，并尝试申请唤醒锁。请为 Termux 关闭电池优化并允许后台运行。
安卓强制停止应用或系统清理后可能离线，重新打开 Termux 恢复；若希望重启后启动，需要另外配置 Termux:Boot。
不能保证安卓上永久在线。

默认只能操作 Termux 环境。若需要访问手机共享存储，手动执行 `termux-setup-storage` 并授权，再选择授权目录。
不能访问其他应用私有数据，不能自动点击安卓应用。

## 验证情况

已完成 Python、JavaScript 和 PowerShell 解析检查，以及云端安卓／Windows 包生成、架构分离、端口和命令格式校验。
Windows FRP 下载包使用 GitHub 官方发布的 SHA256 验证。
没有 Windows／安卓实机，系统安装、后台保活及真实远程任务尚未实机验证。Linux 既有接入继续保留。
